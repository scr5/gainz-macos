# gainz-macos
A native Mac OS Application for Small-Cap/Flow-Float Traders

- Top Gainers for Pre-Market, Regular Session & After-Hours
- High of Day and Momoentum Alerts
- Halt Notificatons
- Charting with the option to use your Tradingview Subscription for complete market data
- News
- Company Details including Float, Market Cap etc
- Access SEC Filings directly from EDGAR and open documents with in the app
- Option to integrate the Ask Edgar API for exhanced Dilution information, this requires a paid plan with Ask Edgar https://www.askedgar.io/platform/api

Log in credentials can be created here https://higherlows.io/gainz
